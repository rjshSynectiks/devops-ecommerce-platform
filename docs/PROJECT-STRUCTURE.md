# Project Structure

## services

Contains the backend microservices.

### api-gateway
Entry point for frontend/API traffic.

### user-service
Responsible for users and authentication-related functionality.

### product-service
Responsible for product catalog functionality.

### order-service
Responsible for order management.

## frontend

React frontend application.

## infrastructure

Infrastructure and deployment configuration.

### docker
Docker-related configuration.

### kubernetes
Kubernetes manifests.

### helm
Helm charts.

## monitoring

Prometheus and Grafana configuration.

## ci-cd

Jenkins and GitHub Actions pipelines.

## docs

Architecture, deployment, troubleshooting and incident documentation.
