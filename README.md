# DevOps E-Commerce Platform

A production-style microservices application designed for DevOps engineering practice.

## Technology Stack

- Java
- Spring Boot
- Maven
- React
- PostgreSQL
- Docker
- Kubernetes
- Jenkins
- GitHub Actions
- Prometheus
- Grafana
- AWS
- Helm
- Git

## Microservices

- API Gateway
- User Service
- Product Service
- Order Service

## DevOps Areas

- Git workflow
- Maven builds
- Unit testing
- Docker image creation
- CI/CD pipelines
- Kubernetes deployments
- Monitoring
- Logging
- Troubleshooting
- Incident management
- Rollback
- Production support
- Root Cause Analysis

## Project Goal

This project simulates the responsibilities of a DevOps engineer working on an existing application rather than simply building an application from scratch.
